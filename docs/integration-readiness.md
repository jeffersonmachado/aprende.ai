# Integração planejada com o r-agent2

## Objetivo
Manter o aprende.AI separado no domínio, mas pronto para conversar com o r-agent2 quando os dois lados estiverem maduros.

## Estratégia
1. APIs próprias no aprende.AI
2. Eventos em `integration_events`
3. Regras de tenant compatíveis
4. Mesmo padrão de organização técnica

## Casos previstos
- gerar trilhas corretivas a partir de eventos operacionais
- criar casos de estudo a partir de conversas anonimizadas
- alimentar competências com sinais vindos do atendimento
- recomendar conteúdo para agentes do r-agent2
